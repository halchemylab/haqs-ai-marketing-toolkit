# Legacy Script Wrappers

These files are compatibility wrappers around the packaged modules in
`haqs_toolkit/`.

Prefer these commands for new work:

```powershell
haqs-toolkit
haqs-campaign
haqs-event
haqs-check
python -m haqs_toolkit.generators.<module_name>
```

Use the wrappers here only when an older note, shortcut, or automation expects a
script file.
